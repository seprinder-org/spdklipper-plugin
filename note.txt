Cách chạy trên Raspberry Pi (development):
1. python3 -m venv .venv
2. source .venv/bin/activate
3. pip install -r scripts/requirements.txt
4. Copy .env.example thành .env và điền thông tin
5. Bảo vệ file .env: chmod 600 .env
6. python3 plugin/main.py

Lập trình trên Desktop.
Chạy trực tiếp bằng Python (không cần PyInstaller).

Nếu chạy không được thì thử chạy lệnh sau, giúp cài thư viện 32-bit để chạy được binary 32-bit trên hệ điều hành 64-bit:
sudo dpkg --add-architecture armhf
sudo apt update
sudo apt install libc6:armhf libstdc++6:armhf

=== BẢO MẬT KEY TRÊN RASPBERRY PI ===

1. File .env chứa HOST_CONNECT, HOST_SERVER - phải được bảo vệ:
     chmod 600 .env   (chỉ owner mới đọc được)

2. SPD_SECRET_KEY là KHÔNG BẮT BUỘC trong .env.
   Nếu để trống, hệ thống tự sinh key và lưu trong database.
   => An toàn hơn vì key không nằm trong file plaintext.

3. Database db.sqlite3 chứa token đã mã hoá (Fernet).
   Tự động set chmod 600 khi khởi chạy.

4. Mã hoá .env bằng AES-256:
     ./scripts/secure_env.sh lock     # Mã hoá .env -> .env.enc
     ./scripts/secure_env.sh unlock   # Giải mã .env.enc -> .env
     ./scripts/secure_env.sh status   # Kiểm tra trạng thái

5. Khi cài bằng install.sh, các bước bảo mật tự động chạy:
   - .env -> chmod 600
   - db.sqlite3 -> chmod 600
   - Thư mục config -> chmod 700
